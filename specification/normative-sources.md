# Normative sources and traceability

UML semantic coverage MUST be reconciled against OMG UML 2.5.1, not inferred solely from diagram conventions.

- UML specification: https://www.omg.org/spec/UML/2.5.1/PDF
- UML abstract syntax metamodel: https://www.omg.org/spec/UML/20161101/UML.xmi
- UML primitive types: https://www.omg.org/spec/UML/20161101/PrimitiveTypes.xmi
- UML standard profile: https://www.omg.org/spec/UML/20161101/StandardProfile.xmi
- UML diagram interchange: https://www.omg.org/spec/UML/20161101/UMLDI.xmi

These resources are maintained by the Object Management Group. The project does not claim endorsement by OMG.

## Traceability policy

Each completed metaclass entry should identify the normative metaclass, generalizations, owned and inherited features, constraints, YAML representation, schema location, and positive/negative conformance cases. A metaclass MUST NOT be marked `verified` without this evidence.
