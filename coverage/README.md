# Coverage tracking

Coverage is **not** complete. The manifest is a seed inventory of major UML areas, not an exhaustive official metaclass inventory.

The authoritative inventory must be generated or independently reconciled against the OMG UML 2.5.1 normative metamodel. A row with `status: partial` means some constructs are represented in the current draft, not that the corresponding UML package is fully supported.

Status values: `missing`, `partial`, `complete`, `verified`. Only `verified` indicates reconciliation against the normative source plus conformance evidence.

See [roadmap](../roadmap/full-uml-coverage.md).
